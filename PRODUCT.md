# Product

## Register

product

## Users

DeepSeek Harness users who explore follow-up questions without losing the original conversation.

## Product Purpose

Browse native sessions and promoted branches by workspace, then open the chosen conversation in the native app.

## Brand Personality

Native, restrained, clear. Match DeepSeek Harness typography, semantic colors and interaction patterns.

## Anti-references

An isolated decorative dashboard; a narrow browser-default directory surrounded by unused space.

## Design Principles

- Keep the native conversation workflow central.
- Make parent and branch relationships readable.
- Use real session titles and visible branch metadata.
- Keep controls consistent with the host application.

## Accessibility & Inclusion

Provide keyboard access, visible focus, labeled icon buttons and theme-aware semantic colors. Avoid unnecessary motion.
